Privacy Policy for Muse Controls

Last updated: October 7, 2026

Publisher: David DiCillo

Muse Controls is a Stream Deck plugin for macOS. It controls the Meta Muse Mac app that is already installed and signed in on your own Mac.

What the plugin collects

Nothing. The plugin collects no personal data, runs no analytics, shows no ads, and sends no data to the publisher or to any third party. It makes no network calls of its own.

What stays on your Mac

  • Saved prompts: The only text the plugin stores is the prompt you type into a Send Saved Prompt key. That text is stored by Stream Deck in that key settings on your Mac, and nowhere else.
  • Clipboard, briefly: To check for an unsent draft, insert a saved prompt, and verify the result, the helper temporarily places text on the macOS clipboard, then restores the clipboard previous contents. It does not log the draft or the prompt. A clipboard history app could retain text while it is on the clipboard, so avoid putting secrets in saved prompts if you use a clipboard manager.
  • Conversation history: The plugin does not read, store, or transmit your Muse conversation history.
  • Credentials: The plugin stores no Muse credentials and needs no Meta API key. It works through the Muse app you are already signed into.

Permissions

The plugin needs macOS Accessibility access for Stream Deck so it can operate Muse visible controls. It does not change microphone or privacy permissions itself. Dictation uses Muse own dictation control, and any microphone permission belongs to the Muse app.

Changes and contact

If a future version changes any of the above, this policy will be updated before that version is published. Questions: use the support link on the Muse Controls Marketplace listing.
