## Description (955 characters, inside the 250 to 1,500 range)

Muse Controls adds five Stream Deck actions for Meta Muse on macOS. Open Muse in Main chat, create a new Side Chat, start or stop dictation from a key, finish and send spoken text, or send a saved prompt configured for each key.

Open Muse launches or focuses Muse and goes straight to Main chat. New Side Chat starts a fresh conversation. Dictate starts dictation in the chat you are viewing if Muse is frontmost, and in Main chat if you are in another app. The Dictate key changes to Stop while Muse is recording. Finish and Send submits a finished dictation or a draft already in the composer. Send Saved Prompt stores one prompt per key in Stream Deck settings.

It works with the installed, signed-in Muse app and requires macOS 12 or later, Stream Deck 7.1 or later, and Accessibility access for Stream Deck. No Meta API key is needed, and the plugin does not read conversation history. This is an independent plugin and is not affiliated with Meta.

## Release notes, v0.4.0.0

First public release of Muse Controls. Five actions: Open Muse, New Side Chat, Dictate, Finish and Send, and Send Saved Prompt. The Dictate key changes appearance while Muse is recording, to a Stop state. Send Saved Prompt stores its prompt per key in Stream Deck settings, and shows an error instead of sending when no prompt is set or a draft is already in the composer. macOS only. Requires the Meta Muse Mac app, signed in, and Accessibility access for Stream Deck.
